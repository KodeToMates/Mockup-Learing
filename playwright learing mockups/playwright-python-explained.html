1What is Playwright?

Playwright is a library (made by Microsoft) that lets your code drive a real browser: Chromium (Chrome/Edge), Firefox and WebKit (Safari). Anything you can do with a mouse and keyboard, a script can do.

It runs headless by default (no visible window, faster). Use headless=False to watch it work while learning.

2Setup

Two things to install: the Python package, then the browsers.

# 1. (optional) make a virtual environment
python -m venv .venv
.venv\Scripts\activate          # Windows

# 2. install the library
pip install playwright

# 3. download the browsers (one time, ~300MB)
playwright install
Want the pytest style for testing? Install pip install pytest-playwright instead. It brings Playwright and gives you ready-made page fixtures (section 8).
If you get "Executable doesn't exist", you skipped playwright install.

3Your first script

Open a page, read its title, take a screenshot.

from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch(headless=False)   # 1. start browser
    page = browser.new_page()                        # 2. open a tab
    page.goto("https://example.com")                # 3. go to URL
    print(page.title())                              # 4. read the title
    page.screenshot(path="example.png")              # 5. screenshot
    browser.close()                                  # 6. clean up

Browser

The application itself. Launch once.

Context

A fresh, isolated profile (own cookies and storage). Like an incognito window.

Page

One tab. This is where you click and type.

browser.new_page() creates a context and a page for you. For more control use browser.new_context() then context.new_page().

4Locators: finding things on the page

A locator describes an element. Prefer ones that match what a user sees (role, label, text) over fragile CSS.

MethodExampleQuality
get_by_rolepage.get_by_role("button", name="Sign in")best
get_by_labelpage.get_by_label("Email")great for forms
get_by_placeholderpage.get_by_placeholder("Search")good
get_by_textpage.get_by_text("Welcome")good
get_by_test_idpage.get_by_test_id("submit")stable (needs data-testid)
locator(css)page.locator("#login .btn")ok
locator(xpath)page.locator("//div[3]/a")fragile
Many matches? Narrow with .first, .nth(2), .filter(has_text="..."), or chain: page.locator("form").get_by_role("button"). Playwright raises an error if a locator matches more than one element when you act on it ("strict mode").

7Auto-waiting: why Playwright is less flaky

Before clicking, Playwright automatically waits until the element is visible, enabled, stable and not covered. You rarely need sleep().

AVOID 
time.sleep(5)      # slow and unreliable
page.click("#go")
DO 
page.get_by_role("button",
  name="Go").click()   # waits by itself

When you need to wait explicitly

loc.wait_for(state="visible")
page.wait_for_url("**/dashboard")
page.wait_for_load_state("networkidle")
with page.expect_response("**/api/users") as r:   # wait for an API call
    page.get_by_text("Load").click()
print(r.value.json())
page.set_default_timeout(10000)               # 10 s instead of default 30 s

8Writing tests with pytest

Install pytest-playwright. You get a page argument automatically, a fresh one per test.

# test_login.py
import re
from playwright.sync_api import Page, expect

def test_login(page: Page):
    page.goto("https://myapp.com/login")
    page.get_by_label("Email").fill("me@test.com")
    page.get_by_label("Password").fill("secret")
    page.get_by_role("button", name="Sign in").click()

    expect(page).to_have_url(re.compile(r".*/dashboard"))
    expect(page.get_by_text("Welcome")).to_be_visible()

Run it

pytest                              # headless, chromium
pytest --headed                     # watch the browser
pytest --browser firefox --browser webkit
pytest --slowmo 500                 # slow down 0.5s per action
pytest --tracing on                 # record a trace
pytest -k login                     # only tests with "login"
Use expect(...) for assertions. It retries until the condition is true or times out, unlike a plain assert which checks only once.

Common expect checks

to_be_visible()element is shown
to_have_text("Hi")exact text match
to_contain_text("Hi")partial text match
to_have_value("x")input value
to_be_enabled() / to_be_disabled()button state
to_have_count(3)number of matches
to_have_title("..") / to_have_url("..")page checks

10Sync vs Async API

Playwright for Python ships two flavours. Beginners should start with sync.

Sync (simple)

from playwright.sync_api import sync_playwright
with sync_playwright() as p:
    b = p.chromium.launch()
    pg = b.new_page()
    pg.goto("https://example.com")

Reads top to bottom. Great for scripts and pytest.

Async (concurrent)

import asyncio
from playwright.async_api import async_playwright
async def main():
    async with async_playwright() as p:
        b = await p.chromium.launch()
        pg = await b.new_page()
        await pg.goto("https://example.com")
asyncio.run(main())

Use inside async apps (FastAPI) or to run many pages at once.

Don't use the sync API inside an asyncio loop (Jupyter, FastAPI). You will get "Sync API inside the asyncio loop". Switch to async.
