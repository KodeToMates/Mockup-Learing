1What is Next.js?

Next.js is a framework built on top of React. React only builds the user interface. Next.js adds everything else a real website needs: routing, server rendering, an API layer, and speed optimizations.

React alone you assemble it
  • Pick and configure a router
  • Set up bundler and build tools
  • Build a separate backend server
  • Work hard for SEO and fast loading
React + Next.js batteries included
  • Routing comes from your folders
  • Bundling and compiling built in
  • API endpoints inside the same project
  • Server rendering for SEO and speed
Analogy: React is the engine. Next.js is the whole car: wheels, steering, dashboard and all.

6Special files

Files with magic names that Next.js understands.

FilePurpose
page.jsThe UI for a route. Makes the folder a public URL.
layout.jsShared wrapper (nav, footer) around pages. Stays mounted while you navigate.
loading.jsInstant loading UI shown while the page fetches data.
error.jsFriendly fallback when something throws an error.
not-found.jsCustom 404 page.
route.jsAPI endpoint (export GET, POST, ...).
middleware.js / proxy.jsCode that runs before a request finishes, e.g. redirect users who are not logged in.

}

7Server vs Client Components

The most important idea in modern Next.js. Components are Server Components by default. Add 'use client' only when you need interactivity.

🖥️ Server Component default
  • Runs only on the server
  • Can fetch data and read secrets directly
  • Sends no JavaScript to the browser
  • No useState, useEffect or onClick
🖱️ Client Component 'use client'
  • Handles clicks, forms and state
  • Can use browser APIs (window, localStorage)
  • Can use React hooks
  • Adds JavaScript to the page bundle
// Server Component (default)
export default async function Page() {
  const res = await fetch('https://api.example.com/posts');
  const posts = await res.json();
  return <ul>{posts.map(p =>
    <li key={p.id}>{p.title}</li>)}</ul>;
}
'use client';
import { useState } from 'react';

export default function Counter() {
  const [n, setN] = useState(0);
  return <button onClick={() => setN(n+1)}>
    Clicked {n}
  </button>;
}
Where is each part of this blog page rendered? Click a block.

Most of the page stays on the server. Only the interactive blocks ship JavaScript.

Tip: keep Client Components small and near the "leaves" of your tree. Fetch data in Server Components and pass it down as props.

8Rendering modes

How and when a page's HTML is created. Pick a mode.

How you choose
// Static page, rebuilt in the background every 60 seconds (ISR)
export const revalidate = 60;

// Force fresh server rendering on every request
export const dynamic = 'force-dynamic';
Next.js picks static automatically when a page has no per-request data. You only opt in to dynamic when you need it.

9Data fetching & API routes

Fetch inside async Server Components, or build your own endpoints with Route Handlers.

Fetch in a page
export default async function Users() {
  const res = await fetch('https://api.example.com/users');
  const users = await res.json();
  return <ul>{users.map(u =>
    <li key={u.id}>{u.name}</li>)}</ul>;
}
Create an API endpoint
// app/api/hello/route.js
export async function GET() {
  return Response.json({ message: 'Hello!' });
}

export async function POST(request) {
  const body = await request.json();
  return Response.json({ received: body });
}

10Handy built-in tools

🖼️ next/image
<Image src="/hero.png"
  width={800} height={400}
  alt="Hero" />

Auto-resizes, lazy-loads, modern formats.

🔤 next/font
import { Inter } from
  'next/font/google';
const inter = Inter({});

Self-hosted fonts with no layout shift.

🏷️ Metadata
export const metadata = {
  title: 'My Page',
  description: '...'
};

Titles and SEO tags per page.

↪️ Redirects
import { redirect }
  from 'next/navigation';
redirect('/login');

Send users to another route.

🔐 Env variables
# .env.local
DB_URL=secret
NEXT_PUBLIC_SITE=my.com

Only NEXT_PUBLIC_ ones reach the browser.

⏳ loading.js
export default function
Loading() {
  return <p>Loading...</p>;
}

Instant skeleton while data loads.
