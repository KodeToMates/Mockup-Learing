BMAD Guide

What is BMAD?

BMad Method is an AI-driven development framework. Instead of one chatbot doing everything, it splits software work into specialist agents (analyst, PM, architect, UX, developer) and workflows (PRD, architecture, stories, build, review), each installed as a Claude Code skill. You walk a project from idea to shipped code, leaving a trail of documents each step builds on.

AGENTS

Personas with a job

Mary, John, Winston, Sally and Amelia each own a phase and a menu of actions.

WORKFLOWS

Guided processes

Skills like PRD, Architecture, Epics & Stories walk you through questions and write the document.

ARTIFACTS

Files, not chat

Outputs land in _bmad-output so the next skill can read them. Chat can be thrown away.

CONFIG

Customizable

Override any skill via TOML in _bmad/custom: persona, menu, facts, steps.

Your workspace already has .claude/skills (29 BMAD skills), _bmad (config, scripts, module) and _bmad-output (generated docs).

What are skills?

A skill is a folder containing a SKILL.md: a name, a one-line description, and instructions. Claude Code loads the description automatically and pulls in the full instructions only when your request matches, or when you type /skill-name.

.claude/skills/bmad-prd/ ├── SKILL.md ← name + description (frontmatter) + instructions ├── customize.toml ← default settings you can override ├── assets/ ← templates the skill fills in ├── references/ ← extra docs loaded on demand ├── steps/ ← step files, loaded one at a time └── scripts/ ← helpers run through uv

Two kinds of BMAD skills

AGENT SKILL

bmad-agent-*

Adopts a persona, greets you, shows a menu of capabilities. Stays in character until dismissed.

WORKFLOW SKILL

bmad-prd, bmad-build…

Runs one process end to end and writes an output document or code.

Three ways to trigger one

/bmad-prd type the slash command "talk to John" say what the description says "create a PRD for my app" just describe the task; Claude matches it

How to use it: the flow

Click a step. Early steps are optional; PRD to build is the main path. Run each skill in a fresh chat so the context stays clean.

Quick start

/bmad-help see where you are and what to do next /bmad-agent-pm meet John, pick PRD from the menu /bmad-agent-ux-designer then Sally for UX, Winston for architecture /bmad-build implement a story or feature

The agents

Each agent has a menu code. Say the code, a number, or describe what you want.

Where things live

Skills are the instructions. _bmad is the runtime they depend on. Output goes to _bmad-output.

d:\new repos\ ├── .claude/skills/ 29 bmad-* skills (what Claude Code loads) ├── _bmad/ │ ├── config.toml your name, language, output folders │ ├── scripts/ resolve_config.py, memlog.py … (run with uv) │ ├── bmm/ the BMad Method module │ └── custom/ your overrides go here └── _bmad-output/ PRDs, specs, architecture, stories

Customizing

Never edit a skill's customize.toml; updates overwrite it. Create _bmad/custom/<skill>.toml (team) or .user.toml (personal) to change persona, menu items, or add persistent facts. /bmad-customize does this for you.

Requirement: the skills call scripts through uv. Install it if a skill reports it can't run.
