1What is this field called?

The category name is Computer Networking (people also say just "Networking", and the job is Network Engineering). It is about connecting devices so they can share data. WiFi is one part of it, called Wireless LAN (WLAN).

🏠

LAN

Local Area Network

Devices in one place: your home, office or school. Connected by cable (Ethernet) or WiFi.

📶

WLAN

Wireless LAN

A LAN that uses radio waves. This is what everyone calls "WiFi".

🌍

WAN

Wide Area Network

Many LANs joined over long distance. The Internet is the biggest WAN.

Networking = hardware (things you can touch) + software / protocols (rules that devices follow). Both are needed. Section 3 splits them clearly.

3Hardware vs Software

Think of roads and traffic rules. Hardware is the road; software is the rules.

HARDWARE

Physical things

  • Cables: Ethernet (copper), fiber optic
  • NIC: network card / WiFi chip in your device
  • Modem: talks to the ISP line
  • Router: connects networks, picks the path
  • Switch: connects wired devices in a LAN
  • Access Point: broadcasts WiFi
  • Repeater / Mesh node: extends WiFi range
SOFTWARE

Rules and programs

  • IP: addresses for devices
  • DHCP: hands out IP addresses automatically
  • DNS: turns names into IPs
  • TCP / UDP: how data is delivered
  • HTTP / HTTPS: web pages
  • WPA2 / WPA3: WiFi password encryption
  • Firewall: allows or blocks traffic
  • Router firmware: the OS inside the router
Example: opening google.com. Hardware carries the signal (WiFi chip, router, fiber). Software decides where it goes (DNS finds the IP, TCP delivers, HTTPS secures).

The WiFi name you see in the list, e.g. "Home_WiFi".

Security

WPA3 (best) > WPA2 (ok) > WEP / Open (unsafe). Always use a strong password.

5IP address, MAC and DHCP

Every device needs an address so data knows where to go.

IP address

192.168.1.23

Logical address. It can change. Private (192.168.x.x, 10.x.x.x) is used inside your home; public is what the internet sees.

MAC address

A4:C3:F0:85:1B:7E

Physical ID burned into the network chip. Normally fixed. Used inside the local network.

6DNS: the phonebook of the internet

Computers use numbers, humans use names. DNS translates google.com to 142.250.x.x.

If you can ping 8.8.8.8 but websites do not open, the problem is DNS, not your internet.

8TCP vs UDP, ports and protocols

TCP: careful

Checks that every piece arrived, in order, and resends lost ones. Slower but reliable. Web, email, downloads.

UDP: fast

Sends and does not check. Faster, may lose pieces. Video calls, games, live streams, DNS.

Common ports and protocols

PortProtocolUsed for
An IP address finds the device; a port finds the app on that device (like building address + flat number).

10"My WiFi is not working" checklist

Go top to bottom. Most problems are solved in the first four steps.

1. Is WiFi turned on and airplane mode off on your device?
2. Do other devices work? Yes: problem is your device. No: problem is router / ISP.
3. Restart the router: unplug 30 seconds, plug back in. Wait 2 minutes.
4. Forget the WiFi network on your device and reconnect with the password.
5. Check cables: Ethernet and modem line fully inserted, lights on?
6. ping 8.8.8.8 works but sites do not open? Change DNS to 8.8.8.8 or 1.1.1.1.
7. Weak signal? Move closer, switch to 2.4 GHz for range, or add a mesh node.
8. Still down? Call your ISP, the line may be cut.
